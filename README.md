# MetaFlow Studio

MetaICT용으로 새롭게 설계한 AI 콘텐츠 제작·협업 플랫폼 시제품입니다.

## 핵심 흐름
1. 프로젝트 생성
2. Mainboard 무한 캔버스에서 자료·메모·이미지 구성
3. Storyboard 장면 구성
4. AI Copilot으로 기획/카피/스토리보드 보조
5. 팀 댓글과 검토 요청
6. Asset Library에서 파일 재사용

## 시제품 기능
- 프로젝트 대시보드
- Mainboard / Storyboard / Review 구조
- AI Copilot UX
- 팀 협업 / 댓글 / 검토 UI
- 자산 라이브러리
- 반응형 UI/UX
